# ai-fly 图标 · 方向 B（节点 + 链路）

两点一弧流：实心节点（本机 AI 服务）自冠部起飞，一道真圆弧翼形光束掠过 fabric，水平滑入右上的开口环（朋友的开放端口）；环内一枚亮芯——同一服务抵达 127.0.0.1，即 "share services, simply"。

- 有别于 OpenDWeb 四点玻璃连接器：两点、单弧、纯琥珀家族（#fdd309→#f5b800→#c99700），精密几何而非有机 blob。
- 弧束恒定曲率、渐细如翼，最细笔画 58、最小间隙 66（画布 6.4%/1024），渐变在 16px 退化为清晰实心剪影。
- tray 为同构纯黑 alpha 单色版：节点 1.0 / 弧束 1→0.78 / 开口环 0.72 / 亮芯 0.5。
